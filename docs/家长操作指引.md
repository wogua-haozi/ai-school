# 石实 SHINE 数智成长平台 · 家长操作指引

> 请班主任先在 App「班级 → 家长邀请码」生成班级邀请码（全班共用一个），连同学号一起发给家长，家长再按下文操作。
> （学校若对外发布了正式网址/域名，请把下文地址替换后再印发。）

**平台地址**：http://183.36.243.124:18086 （手机浏览器或微信打开均可，建议收藏）

## 一、注册前准备（向班主任要 2 个信息）

| 信息 | 说明 |
|---|---|
| 孩子学号 | 以学校最新通知为准（例如 2773630101），一孩一号 |
| 班级邀请码 | 班主任发放，8 位字母数字，全班共用一个 |

## 二、注册步骤（约 2 分钟）

1. 打开平台地址，进入登录页；
2. 点击「**家长注册（凭邀请码绑定孩子）**」；
3. 依次填写：
   - **手机号**（11 位，就是以后的登录账号）
   - **设置密码**（至少 8 位）＋ 再输一遍确认
   - **孩子学号**、**孩子姓名**（须与学校登记的完全一致，姓名一字不差）
   - **班级邀请码**
   - 您的姓名（可不填）
   - 点击「**与孩子的关系**」选择：父亲 / 母亲 / 爷爷 / 奶奶 / 外公 / 外婆 / 其他家属
4. 点「**注册并绑定**」，看到「注册成功，已绑定孩子」即完成，系统自动进入家长首页。

## 三、注册成功后可以看到

- 孩子的在校成长记录（评价、荣誉等，持续更新）
- 学校发布的通知公告
- 「微光时刻」：上传孩子照片，存入孩子成长档案

## 四、常见问题

| 页面提示 | 原因与解决办法 |
|---|---|
| 学号不存在 / 孩子姓名与学号不符 | 学号或姓名与学校登记不一致，向班主任核对（姓名须一字不差） |
| 邀请码不正确 / 邀请码已作废 | 班主任可能重新生成过新码，请重新向班主任获取 |
| 该手机号已被使用 | 此手机号已注册过，换一个手机号；忘记密码找班主任重置 |
| 提示已达绑定上限 | 每位学生最多自助注册 2 位家长，更多家人请联系班主任由学校绑定 |
| 忘记密码 | 平台无短信找回，请联系班主任在系统里重置 |

**双孩家庭**：一次注册只绑定一个孩子。可分别用两位家长的手机号各自注册；如需一个账号同时看两个孩子，联系班主任补绑。

## 五、以后怎么用

打开同一地址 → 登录页输入**手机号 + 密码**即可，**无需重复注册**。
