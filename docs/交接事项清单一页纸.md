# 石实SHINE 平台 · 交接事项清单

（第一次交接验收随附，请学校相关负责老师过目；各项均不阻塞当前验收，按「建议启动时间」排期即可。）

## 一、需要学校办理的事项

| # | 事项 | 说明 | 建议启动 |
|---|---|---|---|
| 1 | **域名 + HTTPS + ICP 备案** | 正式启用学校自己的网址（如 shine.xxx.edu.cn）需要：①注册一个域名；②以学校为主体做 ICP 备案；③配 HTTPS 证书（开发方配置）。**备案材料**：学校单位证明（统一社会信用代码/法人证书）照片、网站负责人身份证照片与手机号。备案审核周期一般 1~3 周，建议**尽早启动**——完成后 App 与网页都换用正式网址访问。当前测试版用临时地址（HTTP）使用，不影响验收与试用。 | 验收后立即 |
| 2 | （可选）应用商店上架 | 需软件著作权申请授权 + 各商店企业账号认证，全程约 2~3 个月。上架后家长可通过应用商店搜索安装；不上架则继续用安装包直发，功能完全相同。是否推进由校方权衡。 | 校方定 |
| 3 | 隐私政策配合 | 商店上架与合规审查需要学校确认《隐私政策》文本（学生数据收集范围、家长手机号用途等）。平台已按最小化原则设计（监护人手机号仅用于账号绑定与学校联系）；需要时开发方出文本初稿，学校审定。 | 随 #2 |

| # | 事项 | 现状 |
|---|---|---|

| 7 | 通知发布责任人 | 通知公告、扬长课程由管理端发布。请指定 1~2 名发布责任人（管理员权限），正式启用前开通即可。 |
