# 接口文档 —— report-server REST API

> 适用版本：2026-10（批39~43：请假四级+书记 / 学段隔离 / 报告分期 / 采购五级或签 / 班级记分 / 扬长七类 / 撤回普适 / 语音输入）。Base URL：本地开发 `http://localhost:8080`，容器化部署 `http://localhost`（web 容器 nginx 反代 `/api → server`）。交互式接口文档（Swagger UI）：容器 `http://localhost/swagger-ui.html`，本地 `http://localhost:8080/swagger-ui.html`。
>
> **覆盖说明**：本文档维护核心与早期模块的细粒度说明；2026-09 中旬以来新增模块（OA 审批五类 / 学生请假 / 门卫 / 通知中心 / 文明班与班级记分 / 扬长课程 / 邀请码注册 / 素材库 / AI 设置 / 系统参数等）以 **Swagger UI** 为准，关键端点见文末「新模块端点速览」。

## 认证与角色

**认证方式**：JWT Bearer。除 `POST /api/auth/login` 外，所有接口均需请求头 `Authorization: Bearer <token>`（OPTIONS 预检放行；无状态、无 session）。token 由登录接口返回，有效期 12 小时。

**角色与数据范围**（`DataScopeService.visibleClassIds` 一处收口，11 角色）：

| 角色 | 数据范围 |
|---|---|
| `ADMIN` 管理员 | 全校，不受数据范围限制 |
| `LEADER` 校领导 | 全校；设**分管学段**（小学部/初中部）后仅该学段 |
| `GRADE_LEADER` 级长 | 绑定年级（t_grade_binding，可多年级、同年级多人=德育/教学级长） |
| `DIRECTOR` 学成中心主任 | 全校；可另绑**级部主任**岗位（t_grade_binding duty=GRADE_DIRECTOR，请假一级审批与级长同权） |
| `DORM` 生活老师 | 全校（请假代录等行政线豁免） |
| `SECRETARY` 书记 | 全校（7~30 天请假终审） |
| `HEAD_TEACHER` 班主任 | 仅所带班级 |
| `TEACHER` 任课教师 | 仅任课班级（t_teach），所教科目外只读 |
| `PROCUREMENT` 招采 | 任课班级 + 物资核销出库工作台 |
| `PARENT` 家长 | 仅绑定孩子（requireBound） |
| `GUARD` 门卫 | 仅请假核验（JwtAuthFilter 白名单限 /api/student-leave + /api/auth + /api/app） |

下文"学生可见"= 该学生所在班级在当前用户可见班级列表内；"本班班主任"= ADMIN 或该班班主任（任课教师只读）。管理端 `/api/admin/**` 各组**全部仅 ADMIN**（部分页签放开有 ADMIN_ACCESS 的领导），组内不再逐条重复。

> **批51b 一人多岗（权限并集）**：GRADE_LEADER/HEAD_TEACHER/TEACHER/PROCUREMENT 的可见班级 = 任课班（t_teach）∪ 挂名班主任班（t_class.head_teacher_id）∪ 绑定年级班（t_grade_binding）；「该班班主任」一律按挂名认定（不问账号角色，checkClassOperable/请假代录/班级记分/请假详情同口径）。

## 统一响应结构

- 除下文明示"二进制"的文件端点外，统一返回 `ApiResponse<T>`：`{code:int, message:string, data:T}`
  - 成功：`code=0`、`message="ok"`、`data` 为业务数据（无数据时 `data=null`）
  - 失败：`code` 为业务错误码（400/401/403/404/500/502），HTTP 状态码与之一致，`message` 为可直接展示的中文提示
- 参数校验失败：HTTP 400，`message` 形如 `"字段名: 中文消息"`
- **401 行为**：未带/无效/过期 token 返回 HTTP 401 + `{code:401,message:"未登录或登录已过期"}`；登录接口密码错误同样 401。前端收到 401 一律清除 token 并跳转 `/login`
- 403：无权限（如"只有管理员或该班班主任可执行此操作"、"无权访问该学生（数据权限隔离）"）
- 429：登录防爆破——同一用户名连续失败触发锁定（Redis 计数，自动过期），锁定期内登录返回 429「失败次数过多，请 N 分钟后再试」
- **首登强制改密（mcp）**：管理员建号 / 重置密码 / 批量导入下发的账号首次登录后，token 携带待改密标记（JWT `mcp` claim），除 `login / me / PUT password` 三个接口外一律 403「请先修改初始密码后再操作」；改密成功换发新 token（标记清除）。存量旧账号不受影响
- 密码最短 **8 位**（建号 / 重置 / 自助改密全端一致）
- 二进制端点（`/api/report/file/*`、`/api/honor/file/*`、`/api/moment/file/*`、`/api/teacher-honor/file/*`、`/api/profile/photo/{userId}`、`/api/activity/{id}/cover`、`/api/admin/student/{id}/photo`、`/api/score/template`）不包 ApiResponse，直接返回文件字节流，**仍需带 Authorization 头**（iframe 无法带头，前端用 fetch 拉取 Blob）

## AuthController `/api/auth`

- `POST /api/auth/login` — 登录换 token（**公开**）
  - body：`username:String @NotBlank`、`password:String @NotBlank`
  - 返回：`{token, user{id,username,realName,role,perms[]}}`（密码错 401；停用账号 403）。**批49**：`perms` 权限点数组随登录下发（如 `SCORE_ALL`=全校成绩查看），前端入口门控用
- `GET /api/auth/me` — 当前登录用户信息。返回：`{id,username,realName,role}`（待改密态白名单，可访问）
- `PUT /api/auth/password` — 自助修改密码（登录态，待改密账号由此解除限制）。body：`oldPassword/newPassword:String @NotBlank`（新密码 ≥8 位；旧密码错 401）。返回：`{token}`——**新 token**，已清除待改密标记，旧 token 至自然过期前仍有效（批49 起响应含 `user.perms`）

## MetaController `/api/meta`（全部需登录）

- `GET /api/meta/terms` — 学期下拉（当前学期排前）。返回 `Term[]{id,name,startDate,endDate,isCurrent}`
- `GET /api/meta/grades` — 年级列表。返回 `Grade[]`
- `GET /api/meta/grids` — 九维下拉（按 sort）。返回 `Grid[]{id,code,name,icon,sort}`
- `GET /api/meta/indicators` — 评价用二级指标（过滤空名占位）。参数：`gridId?`。返回 `Indicator[]`
- `GET /api/meta/subjects` — 学科列表。返回 `Subject[]`
- `GET /api/meta/my-classes` — 我的班级下拉，**按数据范围过滤**。返回 `[{id,name,gradeId}]`
- `GET /api/meta/teachers` — 在职教职员下拉（**批49** 采购验收人选人用）。非家长启用账号，仅 `[{id,realName}]` 按姓名排序，无敏感列

## StudentController `/api/student`

- `GET /api/student/list` — 学生选择（发起报告用），**按数据范围过滤，仅返回在读**（转出/毕业学生不参与日常业务；全量含历史届请用管理端 `/api/admin/student/list` 的 `status` 筛选）
  - 参数：`classId?`、`keyword?`（姓名模糊）、`page=1`、`size=20`（上限 100）
  - 返回：`{total, records[{id,studentNo,name,gender,classId,status}]}`
- `GET /api/student/{id}` — 单个学生基本信息（App 学生详情）。权限：学生可见
  - 返回：`{id,studentNo,name,gender,classId,status,guardianName,guardianPhone}`

## ScoreController `/api/score`（批49 权限口径：普通教师/班主任全端点 403）

**可见/可操作角色**：ADMIN、SECRETARY（书记）、GRADE_LEADER（级长，限绑定年级）、LEADER（校级领导，按分管学段）；教学处主任/副主任等由 ADMIN 授 `SCORE_ALL` 权限点后**只读**可见。

- `POST /api/score/exam` — 建考试（含科目与满分）。权限：ADMIN/SECRETARY/GRADE_LEADER
  - body：`termId:Long @NotNull`、`name:String @NotBlank`、`examDate:LocalDate @NotNull`、`subjects:[{subjectId:Long, fullScore:BigDecimal}] @NotEmpty`（科目不可重复）
  - 返回：`{examId}`
- `DELETE /api/score/exam/{id}` — 删整场考试。权限：**ADMIN/SECRETARY**
- `PUT /api/score/exam/{id}/entry-open` — 开关录入窗口。body：`open:Boolean`。权限：**ADMIN/SECRETARY**（关窗后 GRADE_LEADER 不可再录）
- `GET /api/score/exam/list` — 考试列表。权限：上述可见角色。返回 `[{id,termId,termName,name,examDate,classMaxTotal,gradeMaxTotal,subjectCount}]`
- `GET /api/score/subject-context` — 某班某考试可操作科目。参数：`examId`、`classId`
  - 返回：`[{subjectId,name,fullScore,classMax,gradeMax,editable}]`。editable：ADMIN/SECRETARY 恒 true；GRADE_LEADER=绑定年级内 true；其余（LEADER/SCORE_ALL）只读 false
- `GET /api/score/list` — 某班某科成绩单。参数：`examId`、`subjectId`、`classId`
  - 返回：`{fullScore, editable, rows[{studentId,studentNo,name,score,classRank,gradeRank}]}`（缺分 null）
- `GET /api/score/export` — 成绩单导出 xlsx（当前成绩单原样落表）。权限同查看。参数：`examId`、`subjectId`、`classId`。**二进制**（文件名如 `成绩_期末考试_语文_初一(2)班.xlsx`）
- `PUT /api/score/entry` — 批量录入。权限：**ADMIN/SECRETARY 全校；GRADE_LEADER 限绑定年级且录入窗口开放**
  - body：`examId/subjectId/classId:Long @NotNull`、`rows:[{studentId:Long, score:BigDecimal}]`（score=null 清除；0≤score≤满分）
  - 返回：`{saved}`
- `POST /api/score/import` — Excel 导入。权限同 entry。multipart：`examId`、`subjectId`、`classId`、`file`
  - 返回：`{saved, skipped[{studentNo,name,reason}]}`（按班内学号匹配，留空不动）
- `GET /api/score/template` — 下载导入模板（该班名册预填 .xlsx）。**二进制**
- `GET /api/leader/score-summary` — 全校/年级成绩汇总（校级领导、级长、ADMIN、SECRETARY、SCORE_ALL；按分管学段/绑定年级过滤）。参数：`examId`。返回按班统计+年级排名

## HonorController `/api/honor`

- `POST /api/honor/upload` — 上传证书 → AI 识别 → 落"待确认"。权限：**ADMIN 或本班班主任**
  - multipart：`studentId`、`file`（≤10MB，jpg/jpeg/png/pdf；图片走 AI 视觉识别，PDF/失败降级手动）
  - 返回：`{honorId, fileUrl, source:ai|manual, detail, parsed{name,level,issuer,date}}`
- `GET /api/honor/list` — 某生荣誉列表（含待确认，时间倒序）。参数：`studentId`（须可见）。返回 `Honor[]{name,level,issuer,honorDate,fileUrl,confirmStatus,...}`
- `PUT /api/honor/{id}` — 编辑待确认荣誉字段。权限同上传。body：`name/level/issuer/honorDate`（均可空）。仅"待确认"态可编辑
- `PUT /api/honor/{id}/confirm` — 确认生效（须先填奖项名）。权限同上传。body：`coin:BigDecimal?`（>0 时扬长币入账）
  - 返回：`{termId}`（入账学期，未入账 null）
- `DELETE /api/honor/{id}` — 删除（仅待确认态，已确认的关联币账不可删）。权限同上传
- `GET /api/honor/file/{id}` — 证书原件预览（inline 图片/PDF）。权限：学生可见。**二进制**

## ActivityController `/api/activity`

- `GET /api/activity/list` — 活动列表（开始时间倒序）。需登录。返回 `Activity[]{id,title,type,startTime,place,intro,coverUrl,...}`
- `POST /api/activity` — 建活动。**仅 ADMIN**。body：`title:String @NotBlank`、`type/startTime/place/intro?`。返回 `{activityId}`
- `PUT /api/activity/{id}` — 改活动。**仅 ADMIN**。body 同上
- `DELETE /api/activity/{id}` — 删活动。**仅 ADMIN**（已有参与记录则 400）
- `POST /api/activity/{id}/cover` — 传封面。**仅 ADMIN**。multipart：`file`（jpg/jpeg/png ≤5MB，重复上传覆盖）。返回 `{coverUrl}`
- `GET /api/activity/{id}/cover` — 封面图。需登录。**二进制**（未上传 404）
- `GET /api/activity/{id}/signups` — 某活动参与记录，**按数据范围过滤**。返回 `[{signupId,studentId,studentName,classId,signupTime,checkinTime,award,performance}]`

## MomentController `/api/moment`（微光信箱）

- `POST /api/moment` — 发微光（教师随手拍）。权限：**ADMIN 或该班班主任**
  - multipart：`classId:Long @NotNull`、`sceneTag:String @NotNull`（场景标签）、`studentIds?:Long[]`（圈选学生，可空）、`note?`、`photo`（图片）
  - 返回：`{momentId,...}`。微光自动进班级轮播、学生「闪光时刻」、AI 寄语上下文与报告「成长掠影」
  - **批48**：手动发布成功后，圈选的每位学生自动 +1 扬长币（sourceType=`微光`；评价联动生成的 EVAL_SYNC 微光不重复发）
- `GET /api/moment/class` — 班级最近微光（班级页轮播）。参数：`classId`（班级须可见）、`limit=20`
- `GET /api/moment/student` — 某生微光列表（学生详情「闪光时刻」）。参数：`studentId`（须可见）、`limit=50`
- `DELETE /api/moment/{id}` — 删除。权限：记录教师本人或 ADMIN。**批48**：手动微光删除时自动冲回已发的 1 扬长币（负流水留痕）
- `GET /api/moment/file/{id}` — 微光照片预览（inline）。需登录。**二进制**

## AiController `/api/ai`（读=学生可见；生成/保存寄语=**ADMIN 或本班班主任**）

- `POST /api/ai/analysis` — 学业分析（规则引擎硬数字，不调大模型）。body：`studentId/termId:Long @NotNull`（无成绩 400）
  - 返回：`{advantage, toImprove, trend, alerts[]}`
- `POST /api/ai/comment-draft` — 班主任寄语草稿·**同步版**（AI 失败降级模板，存 t_comment.ai_draft）。body 同上
  - 返回：`{draft, source:llm|template, status}`。单发生成仍可用；页面已默认走下方任务队列
- `GET /api/ai/comment` — 寄语现状。参数：`studentId`、`termId`。返回 `{content, aiDraft, status}`（无记录 status="无"）
- `GET /api/ai/comment/export` — 寄语导出（班级×学期 → xlsx，含草稿与生效内容）。权限：**ADMIN 或该班班主任**。参数：`classId`、`termId`。**二进制**（文件名如 `寄语_初一(2)班_2025年秋季学期.xlsx`）
- `PUT /api/ai/comment` — 保存/确认寄语（confirm=true 才进报告）
  - body：`studentId/termId:Long @NotNull`、`content:String @NotNull`、`confirm:boolean`。返回同 GET
- `POST /api/ai/summary` — 成长总结草稿·**同步版**（不落库仅展示）。body 同 analysis
  - 返回：`{raw, blocks{本学期亮点,学习发展,综合素质发展,下一阶段建议}, source}`
- `POST /api/ai/tasks` — **任务队列·提交**（入队即返；切页/关浏览器后端照跑；同学生同类型未完成自动去重复用）
  - body：`type:String @NotNull`（`COMMENT`=寄语 / `SUMMARY`=总结）、`studentId/termId:Long @NotNull`。返回 `{taskId}`
- `GET /api/ai/tasks/{id}` — **任务队列·详情**（轮询取果）。权限：任务学生可见
  - 返回：`{taskId,type,studentId,termId,status(排队/生成中/成功/失败),source,error,createTime,startedTime,finishedTime, queuePosition?, result?}`——排队中附 `queuePosition`（前方第 N 位）；成功后 `result` 即同步接口的 data（COMMENT=`{draft,source,...}`，SUMMARY=`{raw,blocks,source}`）
- `GET /api/ai/tasks/mine` — **任务队列·我提交的近期任务**（全局任务面板数据源，含学生姓名）。参数：`limit=50`（上限 200）。按 `created_by` 过滤，**互相不可见**

**任务队列对接模式**：提交拿 taskId → 轮询 `mine`（前端 2s）驱动列表/进度 → 关心的任务转 `详情` 拿结果体。寄语结果另持久化于 `t_comment.ai_draft`（`GET /api/ai/comment` 可随时回显）；总结仅在任务 `result` 中。服务重启未完成任务自动重新入队。

## 大模型（AI）接入与模型切换指南

### 调用大模型的位置（共 3 处）

| 功能 | 入口 | 模型要求 |
|---|---|---|
| 班主任寄语草稿 | 寄语页「AI 生成草稿」/「本班全部生成」→ `POST /api/ai/tasks(type=COMMENT)` | 纯文本模型 |
| 成长总结四块 | 总结页「AI 分析该学生」→ `POST /api/ai/tasks(type=SUMMARY)` | 纯文本模型 |
| 荣誉证书图片识别 | 证书上传 `POST /api/honor/upload` | **必须多模态（vision）模型** |

协议为 **OpenAI 兼容 Chat Completions**（DeepSeek / 通义千问 / 智谱 / Kimi / OpenAI 均可）。AI 只组织语言，**全部数字与事实由规则引擎计算后注入提示词**，模型无法编造；寄语须教师确认后才进报告。

### 配置在哪、怎么换模型

**Docker 部署（推荐）**：编辑 `docker-compose.override.yml`（首次从 `docker-compose.override.yml.example` 复制），改完 `docker compose up -d report-server`：

```yaml
services:
  report-server:
    environment:
      AISCHOOL_AI_BASE_URL: https://api.deepseek.com   # 供应商 OpenAI 兼容地址
      AISCHOOL_AI_API_KEY: sk-你的key                  # 密钥只放本文件（已 gitignore，勿入库）
      AISCHOOL_AI_MODEL: deepseek-v4-flash             # ★ 换模型只改这一行
      # AISCHOOL_AI_CONCURRENCY: 16                    # 可选：任务并发（默认 16）
```

**本地开发**：改 `report-server/src/main/resources/application.yml` 的 `aischool.ai` 段（base-url / api-key / model / concurrency / timeout-seconds）。

| 环境变量 | 配置项 | 默认 | 说明 |
|---|---|---|---|
| `AISCHOOL_AI_BASE_URL` | aischool.ai.base-url | 空 | 留空 = 不启用 AI |
| `AISCHOOL_AI_API_KEY` | aischool.ai.api-key | 空 | 留空 = 不启用 AI |
| `AISCHOOL_AI_MODEL` | aischool.ai.model | 空 | 留空 = 不启用 AI；**三项须同时配置** |
| `AISCHOOL_AI_CONCURRENCY` | aischool.ai.concurrency | 16 | 任务队列 worker 数 = 对大模型的最大同时在途请求数 |
| — | aischool.ai.timeout-seconds | 120 | 单次 LLM 调用读超时，超时该条降级模板 |

**要同时用证书识别**：`AISCHOOL_AI_MODEL` 须配多模态模型（如 `deepseek-v4-flash-vision-exp` / `qwen-vl` / `glm-4v`）。

### 未配置 / 调用失败时的降级

- 三项配置留空 → 寄语/总结自动降级为**确定性规则模板**（硬数字仍准确），任务正常完成（source=template），前端有提示；证书转手动录入
- 单次调用失败/超时 → 同样降级模板，任务不报错；只有规则引擎本身异常（如无成绩）任务才置"失败"
